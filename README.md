Лабораторная работа № 2 по основам программной инженерии.
Вариант 22.

## Назначение
Учёт клиентов, ведение линии и коэффициентов, приём и расчёт
ставок, денежные операции и отчётность.

- Иванов Константин — специалист по информационным системам.
